# MobEngine
A modular and extensible AI framework for Roblox.

# Feautures
このライブラリでは、
-柔軟な行動システム
自分の好きなAI方式を行動として実装できます(BehaviorTree,UtilityAIなど)
-抽象化された行動用関数
Move()やSearch()等、行動システムと実際の処理を切り離します
-強力な挙動管理システム
同じ行動用関数でも、状況によって簡単に実行する処理を変更できます
-Luauの型サポート
内部で型注釈を厳密にをしているたえ、型補完が効きます
-拡張性
モブAIだけでなく、NPC、武器、スキルなど様々なシステムへ応用可能
